# Correspondance avec l'ancien guide

Cette annexe aide les équipes qui disposent d'intégrations écrites avec l'ancien guide d'intégration des données.

| Sujet de l'ancien guide                                                 | Situation actuelle                                                                                                                                                                                                                                                                                                                      |
| ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Modèle d'import-export (57 entités)                                     | Toutes les entités historiques existent toujours (le traitement UGC, interne, n'est plus documenté). Une cinquantaine d'entités nouvelles : astreintes, matériel et stock, produits, colis, créneaux de réalisation, types de site et de secteur, typologies, zones restreintes, équipages, préférences et périmètres utilisateur, etc. |
| Statuts d'intervention (21, 2, 30, 31, 10, 6, 3 ; 12, 33, 35 en export) | Nouveaux statuts : Accepté (28), Ignoré (9), Externalisé (32). Macro-statuts et règles de transition documentés.                                                                                                                                                                                                                        |
| Type d'intervention : champs principaux                                 | DURATION est obligatoire (avec TASKTYPEID, TASKTYPENAME, TASKTYPEGROUPID).                                                                                                                                                                                                                                                              |
| « Type de la ressource »                                                | Remplacé selon l'option de modélisation par les types d'intervenant ou les types de poste et fonctions.                                                                                                                                                                                                                                 |
| Canaux : CSV, web services, circulation                                 | Toujours valables ; ajout des services REST (JSON/XML), de l'API REST v1, de l'authentification par jeton porteur et de l'envoi vers webhook.                                                                                                                                                                                           |
| Paramétrage (profils et droits, optimisation, vocabulaire, logo)        | Hors périmètre de ce guide ; les listes de droits et les chemins de fichiers de l'ancien guide ne sont pas repris.                                                                                                                                                                                                                      |
| Compte administrateur créé à l'installation                             | Information retirée (sécurité).                                                                                                                                                                                                                                                                                                         |
| Exemples d'import (tableaux décalés, données incohérentes)              | Remplacés par un jeu de données fictif cohérent et vérifié contre le modèle actuel.                                                                                                                                                                                                                                                     |
