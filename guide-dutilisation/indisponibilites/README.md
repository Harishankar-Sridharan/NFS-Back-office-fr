# Indisponibilités

Une indisponibilité est une période pendant laquelle un intervenant ne peut pas recevoir de rendez-vous : congé, réunion, rendez-vous médical, etc. Les indisponibilités s'affichent dans le planning des intervenants.

## Dans cette section

* [Créer une indisponibilité](creer-indisponibilite.md)
* [Rechercher des indisponibilités](rechercher-indisponibilite.md)
* [Gérer les localisations exceptionnelles](localisations-exceptionnelles.md)

Vous pouvez également ajouter une indisponibilité depuis le module **Disponibilités**. Pour en savoir plus, consultez [Disponibilités](../disponibilites/).
