# Clients

Un client est le lieu ou l'organisation chez qui les rendez-vous sont réalisés. Sa fiche contient son adresse géocodée, ses contacts, ses horaires d'ouverture et ses préférences d'affectation.

Les clients se gèrent depuis le module **Planification**.
