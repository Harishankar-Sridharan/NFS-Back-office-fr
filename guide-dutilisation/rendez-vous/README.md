# Rendez-vous

Un rendez-vous correspond à une intervention à réaliser chez un client par un ou plusieurs intervenants. Les rendez-vous se gèrent depuis le module **Planification**.

## Dans cette section

* [Prendre un rendez-vous](prendre-rendez-vous.md) : créer un rendez-vous pour un client et le planifier avec l'optimisation.
* [Planifier un rendez-vous manuellement](planification-manuelle.md) : choisir vous-même l'intervenant, la date et l'heure.
* [Rechercher des rendez-vous](rechercher-rendez-vous.md) : retrouver des rendez-vous et agir sur une sélection.
* [Consulter la fiche d'un rendez-vous](fiche-rendez-vous.md) : lire les informations et utiliser les actions.
* [Modifier un rendez-vous](modifier-rendez-vous.md) : mettre à jour les données d'un rendez-vous.
* [Traiter plusieurs rendez-vous en une fois](planification-en-masse.md) : échanger des tournées, replanifier les rendez-vous d'un intervenant ou planifier une sélection.

Pour comprendre les états d'un rendez-vous, consultez [Comprendre les états des rendez-vous](../introduction/statuts-rendez-vous.md).
