# Suivre les alertes et les messages

Le module **Planification** signale les rendez-vous et les clients qui demandent une action, ainsi que les messages non lus.

## Consulter les alertes de rendez-vous

Les alertes de rendez-vous listent les rendez-vous qui répondent à des critères définis par votre administrateur, par exemple un état sur une période.

1. Ouvrez `Planification > Rendez-vous > Alertes rendez-vous`.
2. Filtrez si besoin par période (**Du**, **Au**), **État** et **Site de travail**.
3. Sélectionnez **Rechercher**.

La liste affiche le nombre de rendez-vous trouvés. Sélectionnez une ligne pour ouvrir la fiche du rendez-vous.

Depuis la liste, selon vos droits :

* **Exporter** produit un fichier CSV du résultat ;
* les actions **Modifier les dates** et **Modifier les intervenants** s'appliquent aux rendez-vous cochés.

Les compteurs de la page d'accueil du module affichent aussi le nombre de rendez-vous de chaque liste. Sélectionnez un compteur pour ouvrir la liste correspondante.

## Consulter les clients en alerte

Le compteur en forme de triangle, dans le bandeau, affiche le nombre de clients en alerte. Sélectionnez-le pour afficher la liste, sous la même forme qu'une recherche de clients.

Vous pouvez aussi ouvrir `Planification > Clients > Liste des clients en alerte`.

## Consulter les alertes de l'application

L'entrée **Alertes**, en bas du menu du module, liste les alertes de l'application auxquelles votre profil est abonné. Si vous n'êtes abonné à aucune alerte, le message « Vous n'avez pas d'abonnement pour les alertes d'application » s'affiche.

Les abonnements sont gérés par l'administrateur. Pour en savoir plus, consultez [Gérer les profils et les droits](../administration/utilisateurs-droits.md).

## Lire les messages non lus

L'icône en forme d'enveloppe du bandeau (info-bulle **Lister les messages non lus**) affiche le nombre de messages non lus. Sélectionnez-la pour ouvrir la messagerie.
