# Présentation du guide

Ce guide présente les fonctionnalités du Backoffice Nomadia Field Service.

Nomadia Field Service est une application web de planification des interventions de terrain. Elle vous permet de prendre des rendez-vous, de les affecter aux intervenants, de suivre le planning et la réalisation des interventions, et d'administrer les données de votre organisation.

Il décrit les fonctionnalités disponibles dans l'application et les procédures nécessaires à leur utilisation.

## À qui s'adresse ce guide ?

Ce guide s'adresse aux utilisateurs autorisés de Nomadia Field Service, notamment :

* les planificateurs, qui prennent les rendez-vous et organisent le planning ;
* les responsables d'équipe et superviseurs, qui suivent l'activité ;
* les administrateurs, qui gèrent les ressources et les données de référence.

## Conventions utilisées

* Les noms des menus, boutons, onglets et champs apparaissent en **gras**.
* Les parcours sont présentés sous la forme `Module > Menu > Page`.
* Les champs suivis d'un astérisque (\*) dans l'application sont obligatoires.
* Les données visibles dans les captures d'écran sont fictives.

{% hint style="info" %}
L'affichage des modules, des menus et des actions peut varier selon les droits attribués à votre profil et selon la configuration de votre environnement.
{% endhint %}
