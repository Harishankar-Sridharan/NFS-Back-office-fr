# Modules complémentaires

Selon votre contrat et les droits de votre profil, d'autres modules s'ajoutent aux modules principaux dans le lanceur d'applications. Un module n'apparaît que si votre profil possède le droit d'accès correspondant.

| Module                | Usage                                                                                    |
| --------------------- | ---------------------------------------------------------------------------------------- |
| **Sectorisation**     | Construire et ajuster des projets de sectorisation des clients sur une carte             |
| **Réalisation**       | Comparer la journée prévue et la journée réalisée d'un intervenant                       |
| **Tracking**          | Suivre la position des ressources équipées d'un dispositif de suivi                      |
| **Rapport**           | Gérer les modèles de rapports et de formulaires                                          |
| Modules personnalisés | Modules propres à votre organisation, dont le nom et le contenu dépendent du paramétrage |

## Accéder à un module

**Navigation :** `Lanceur d'applications > nom du module`

## Sectorisation

Le module **Sectorisation** permet de répartir les clients en secteurs et d'enregistrer ces découpages sous forme de projets.

1. Ouvrez **Sectorisation**. Si la fenêtre **Changer de région** s'affiche, choisissez la région, puis sélectionnez **OK**.
2. Définissez le périmètre de la sectorisation : région, type de client, indicateurs et données à afficher sur la carte.
3. Dans le projet de sectorisation, créez, modifiez, transférez ou supprimez des secteurs. Les clients sans secteur sont signalés comme non affectés.
4. Sauvegardez le projet, puis validez-le pour l'appliquer.

> **\[CAPTURE À PRENDRE]**
>
> * **Écran / Menu :** `Lanceur d'applications > Sectorisation`, après le choix de la région
> * **Contexte / Données à afficher :** carte avec un projet de sectorisation de test et le panneau du projet (secteurs, clients non affectés). Flouter le fond de carte si des adresses de clients sont lisibles.
> * **Rappel :** anonymiser les noms des clients et des ressources, ainsi que le nom de l'organisation de l'environnement de test.

## Réalisation

Le module **Réalisation** compare la journée prévue et la journée réalisée d'un intervenant. Pour en savoir plus, consultez [Réalisation](realisation.md).

## Tracking

Le module **Tracking** affiche les positions des ressources mobiles équipées d'un dispositif de suivi et leurs points de passage : départ, arrivée, visites.

{% hint style="info" %}
Le module **Tracking** nécessite un service de suivi configuré pour votre environnement. L'interface de suivi (filtres, carte) est fournie par ce service.
{% endhint %}

Pour consulter la dernière position des véhicules depuis le module **Planification**, consultez [Utiliser les outils de localisation et d'export](planification/localisation-exports.md).

## Rapport

Le module **Rapport** permet de créer des modèles de formulaires et de générer des rapports d'intervention. Pour en savoir plus, consultez [Rapport](rapport/).

## Modules personnalisés

Votre organisation peut disposer de modules personnalisés, par exemple une page de liens utiles. Leur nom dans le lanceur d'applications et leur contenu dépendent du paramétrage de votre environnement. Pour toute question, contactez votre administrateur.
