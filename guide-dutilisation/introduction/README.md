# Introduction

Nomadia Field Service est une application web. Vous y accédez depuis un navigateur, avec l'adresse et les identifiants fournis par votre administrateur.

## Modules de l'application

Le lanceur d'applications, en haut à gauche de l'écran, donne accès aux modules suivants :

| Module             | Usage principal                                                                         |
| ------------------ | --------------------------------------------------------------------------------------- |
| **Portail**        | Tableau de bord d'accueil : présence du jour, activité du jour, charge prévisionnelle   |
| **Planification**  | Prise de rendez-vous, recherche, planning des intervenants, clients et indisponibilités |
| **Supervision**    | Suivi des rendez-vous, journal des actions, tableaux de bord et analyses                |
| **Disponibilités** | Agenda des disponibilités des intervenants et déclaration d'indisponibilités            |
| **Sectorisation**  | Définition du périmètre de sectorisation                                                |
| **Réalisation**    | Comparaison entre la journée prévue et la journée réalisée d'un intervenant             |
| **Tracking**       | Suivi des équipements de localisation                                                   |
| **Rapport**        | Modèles de rapports et de formulaires                                                   |
| **Administration** | Données de l'entreprise, utilisateurs, paramétrage et fichiers                          |

{% hint style="info" %}
La liste des modules affichée dépend de votre profil et de la configuration de votre environnement.
{% endhint %}
